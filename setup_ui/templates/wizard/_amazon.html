Skill and catalog operations go through Amazon's Skill Management API, which needs your authorization. You register your own credentials for this. There is no shared application and nothing is hosted by this project, so your tokens never touch anyone else's service.

Create a security profile, once
  1. Sign in to the Login with Amazon console with the same Amazon account your Echo devices use. If that account has never opened the developer console, Amazon walks you through free developer registration first.
  2. Click Create a New Security Profile. Three fields are required: Security Profile Name (shown on the consent screen; "Ampere" works), Security Profile Description, and Consent Privacy Notice URL (any https page you control; this bridge's address is fine). Click Save.
  3. Back in the profile table, hover the gear icon in the Manage column and choose Web Settings.
  4. Click Edit (bottom right) and add this exact value to Allowed Return URLs, then Save:

    {{ amazon.redirect_uri or 'set PUBLIC_BASE first' }}

  5. Still on Web Settings: copy the Client ID (it starts with amzn1.application-oa2-client) and click Show Secret to reveal the Client Secret. Paste both into the form below.

Amazon only redirects back to https, which is why this step comes after endpoint validation: by now that origin is proven to answer.
