```
"Alexa, play Radiohead on music assistant"
```

Music Assistant is a bridge. Alexa asks it what to play, it asks your Subsonic server,
and Alexa's native player does the rest: a real queue, per-track metadata and
art, working next and previous, shuffle, loop and repeat. Because it is a Music
Skill rather than a custom skill, multi-room groups work.

It speaks plain Subsonic 1.16.1 with no OpenSubsonic extensions, so it should
work with Navidrome, Airsonic, Airsonic-Advanced, Gonic, LMS, Ampache,
Funkwhale, Nextcloud Music or Astiga. It has been tested against Navidrome.

## What it is not

It is a private, development-stage skill for your own library. It is not on the
Alexa skill store, and it cannot become your default music provider, so you
always name the alias out loud. Read
[What this is](setup/what-this-is/) before starting.
